Build a reading list in minutes

  1. Type a topic — it becomes the folder name.
  2. Add keywords, years, access type and journal houses.
  3. Click Find papers and review the list.
  4. Download PDFs, or just save the reference list (BibTeX, RIS, APA, IEEE, CSV).

Papers you already have are never downloaded twice, even across topics.
